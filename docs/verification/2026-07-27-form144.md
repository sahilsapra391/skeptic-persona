### NAMESPACE TRAP (the finding that matters)

Filing agents disagree on namespace prefixes for the **same form on the same
day**:

| Accession | Agent | Tags |
|---|---|---|
| `0001628280-26-049826` | Workiva | `<own:issuerName>` — every element prefixed |
| `0000764900-26-000029` | (other) | `<issuerName>` — zero `own:` occurrences |

A parser bound to either convention returns **nothing** for the other, with no
error and no warning. `extractAllNs` / `extractFirstNs` in `src/lib/xml.ts`
match both. Both filings are captured as fixtures
(`test/fixtures/form144-prefixed.xml`, `form144-bare.xml`) and are the parse
contract.
