# Bank of Israel interest rate — endpoint verification

**Verified:** 2026-07-28T06:05Z

## Endpoint

`https://www.boi.org.il/PublicApi/GetInterest` → **200**, 112 bytes,
`content-type: application/json; charset=utf-8`. No `ETag`, no `Last-Modified`.

```json
{"currentInterest":3.5,"nextInterestDate":"2026-09-01T00:00:00Z","lastPublishedDate":"2026-07-12T08:59:20.943Z"}
```

The cleanest rate endpoint in the file. It is also the only one that cannot,
on its own, ever produce a post.

## Why it needed a framework change

`detectChange` compares the current observation against an earlier one from
the same response. This endpoint returns exactly one observation, so
`detectChange` always returns null, `isNews` is always false, and the source
would have logged a row every hour forever while every health check showed it
green. **A source that cannot fire is worse than an absent one, because it
looks present.**

`RateSource.singleObservation` opts a source into taking its prior from
`source_state.cursor` — the level we recorded on the previous poll. That is a
level we observed ourselves, which is the same standard of evidence as one
read from a feed, and it is not an inference.

### Why it is opt-in and not the default

Applying the cursor fallback to a history-bearing feed would resurrect old
news. If a rate moved while we were down and has been flat since,
`detectChange` correctly returns null (the framework's rule: "if the series
already moved days ago and has been flat since, that is old news"), but the
cursor still holds the pre-move level and would present a days-old move as
today's. A test asserts no other source sets the flag.

## Field semantics

| Field | Use |
|---|---|
| `currentInterest` | the rate |
| `lastPublishedDate` | when THIS level was published, so it dates the observation |
| `nextInterestDate` | the next scheduled DECISION. **Deliberately ignored** — a scheduled meeting is not a rate, and dating an observation by it would place today's level in the future. |

## Endpoints checked and rejected

| URL | Result |
|---|---|
| `boi.org.il/PublicApi/GetInterestRates` | 404, empty body |
| `boi.org.il/PublicApi/GetInterestList` | 404, empty body |
| `edge.boi.gov.il/FusionEdgeServer/sdmx/...` | 404 |

No history endpoint exists for the policy rate, which is what forced the
capability rather than a config-only addition.
