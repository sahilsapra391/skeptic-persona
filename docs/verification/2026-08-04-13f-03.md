## Semantics proven

- **EXIT** rows carry prior values; current values NULL (never zero — the
  null-vs-zero rule).
- **NEW** rows carry NULL prev and NULL delta-pct (delta over a zero base is
  not a number).
- Value moved but shares equal → **UNCHANGED**: position status is about the
  holding; intra-quarter value drift is the market's.
- A put and a share line on one CUSIP never diff against each other.
- **RESTATEMENT** amendment replaces the period's snapshot; the diff
  recomputes against the restated table (proven: a 1-position restatement
  turns 41 prior positions into EXITs).
- **NEW HOLDINGS** amendment merges — the confidential-treatment reveal
  (proven: 42 + 1 revealed = 43).
- Resolution happens at READ time; stored filings are never mutated, so any
  recompute is always possible.
- One held snapshot computes **nothing** — a photo is not a comparison
  (coverage-guard, structural).
- `coverage_start` = when WE first held a manager's filing (COALESCE, set
  once). Backfill data ≠ observation.

## One implementation, two callers

`parseAndStore13f` extracted from the live poll drain; the backfill relay
route (`13f_backfill`) calls the SAME function with courier-delivered bytes.
The courier (`.github/workflows/thirteenf-backfill.yml`, workflow_dispatch
only) fetches bytes and forwards them untouched; its only judgement is a
filed-date window, and the Worker stores the period `primary_doc` itself
states — a mis-windowed POST is a no-op, never a wrong row. Courier retries
are no-ops end to end (proven: re-POST leaves row counts unchanged).

The watchlist inside the workflow comes from the seed migration in the same
checkout — one source of truth, no second list to drift.
